# 切图助手（Grid Splitter）

把一张图片按网格均匀切开的小工具。支持裁剪、实时预览、无损输出，全部在本机运行，**图片不会上传到任何服务器**。

提供两个版本：

- **网页版**：双击 `index.html` 即用，无需安装任何东西，无需联网
- **命令行版**：适合批量处理或接入自动化流程

## 网页版

双击 `index.html`，或在浏览器中打开。

### 功能

| 功能 | 说明 |
|---|---|
| 拖拽上传 | 点击或把图片拖进画布；支持 JPG / PNG / WebP，可一次多张 |
| 粘贴上传 | 直接按 `Ctrl+V` 粘贴剪贴板里的图片 |
| 裁剪框 | 打开「裁剪区域」后拖动选框，只切选中的部分；八个手柄缩放 |
| 裁剪形状 | **自定义**（任意矩形）/ **正方形** / **矩形**（锁定比例，如 4:3、16:9） |
| 切块完全等分 | 自动微调裁剪尺寸为行列数的整数倍，保证每块像素完全相同 |
| 实时网格 | 切分线、块序号随参数即时更新，所见即所得 |
| 三种切分模式 | 等分 / 按固定像素 / 自定义比例 |
| 无损 PNG | 打开后输出 PNG，逐字节无损；关闭则输出 JPEG，可调质量 |
| 输出余料 | 按尺寸模式下，切不完的边缘单独输出 |
| ZIP 打包 | 一键把所有切块打包下载，文件名按行列自动编号 |

### 裁剪形状

勾选「裁剪区域」后可选三种形状：

| 形状 | 用途 |
|---|---|
| 自定义 | 任意宽高比的矩形，自由拖拽 |
| 正方形 | 强制 1:1，适合头像、部分平台的方形配图 |
| 矩形 | 锁定指定比例，内置 1:1、4:3、3:4、16:9、9:16，也可手填如 `3:2` |

**正方形是怎么保证的**：裁剪框内部用归一化坐标存储，但归一化宽高相等 ≠ 像素相等
（例如 1773×2364 的竖图，归一化 0.5 宽对应 886px，而 0.5 高对应 1182px）。
因此约束按**图片实际像素**换算，确保裁出来的图在像素层面严格是正方形。

### 切块完全等分

当裁剪出的尺寸不能被行/列数整除时（例如 1330 切 3×3），默认会**自动微调**
裁剪尺寸到最接近的可整除值（1330 → 1329），使每块像素完全相同。
界面上会提示实际调整量。关闭该开关后各块会相差 1 像素。

注意：未勾选「裁剪区域」时不做任何微调，保证切的是完整原图；
自定义比例模式下也不微调，以免破坏你指定的比例。

### 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl+V` | 粘贴剪贴板图片 |
| 拖动时按住 `Shift` | 自由模式下临时锁正方形；调整已有选框时锁原比例 |

## 命令行版

需要 Node.js 14 或更高版本。首次使用先安装依赖：

```bash
npm install
```

### 用法

```bash
node slice.js <图片...> [选项]
```

### 常用示例

```bash
# 2×2 等分
node slice.js photo.jpg -r 2 -c 2

# 3×3 等分，输出无损 PNG 到指定目录
node slice.js photo.jpg -r 3 -c 3 --png -o ./out

# 先裁剪（x,y,w,h），再 2×2 切开
node slice.js photo.jpg --crop 100,200,1000,800 -r 2 -c 2

# 自定义比例：列宽 1:2:1，行高 1:1
node slice.js photo.jpg --col-ratio 1,2,1 --row-ratio 1,1

# 按 1080×1080 固定尺寸切，并输出切不完的边缘
node slice.js photo.jpg --tile 1080x1080 --remainder

# 自定义文件名
node slice.js photo.jpg -r 2 -c 2 \
  --prefix "切图_" --name "{base}_第{row}行第{col}列_{w}x{h}"

# 批量处理多张，统一参数
node slice.js a.jpg b.jpg c.jpg -r 3 -c 3 --png -o ./out
```

### 全部选项

| 选项 | 说明 |
|---|---|
| `-r, --rows <n>` | 行数 |
| `-c, --cols <n>` | 列数 |
| `--col-ratio <列表>` | 列宽比，如 `1,2,1` |
| `--row-ratio <列表>` | 行高比，如 `1,1` |
| `--tile <宽x高>` | 按固定像素切，如 `1080x1080` |
| `-o, --out <目录>` | 输出目录，默认是图片同级的 `<文件名>_切片` |
| `--crop <x,y,w,h>` | 先裁剪再切（像素坐标） |
| `--png` / `--jpg` | 输出无损 PNG / JPEG（默认 JPEG） |
| `-q, --quality <50-100>` | JPEG 质量，默认 92 |
| `--remainder` | 按尺寸切时输出边缘余料 |
| `--name <模板>` | 命名模板，默认 `{base}_r{row}c{col}` |
| `--prefix <前缀>` | 文件名前缀 |
| `--quiet` | 只输出摘要 |
| `-h, --help` | 显示帮助 |

命名模板占位符：`{base}` 原名、`{row}` 行号、`{col}` 列号、`{w}` 块宽、`{h}` 块高、`{n}` 序号。

## 关于「切得均匀」

当原图尺寸不能被行列数整除时（例如宽 1773 切 2 列），差值会按累计取整摊到各块，
使各块宽度相差至多 1 像素：

- 宽 1773 切 2 列 → `887` + `886`
- 宽 1773 切 3 列 → `591` × 3
- 宽 1773 切 4 列 → `443` + `443` + `443` + `444`

各块尺寸之和**严格等于**原图尺寸，不留缝、不重叠。网页版与命令行版算法一致，
同一张图同一参数下产出的切块尺寸完全相同。

## 技术说明

- **网页版**无任何外部依赖，ZIP 打包用的 [fflate](https://github.com/101arrowz/fflate) 已内置于 `vendor/`，完全离线可用。
- **命令行版**依赖 [sharp](https://sharp.pixelplumbing.com/) 做图像编解码，未手写任何格式解析。
- **无损保证**：命令行版每个切块直接从源文件解码后裁切，不做中间格式中转
  （sharp 无参 `toBuffer()` 会按源格式重新编码，对 JPEG 源等于二次有损压缩，已规避）。
